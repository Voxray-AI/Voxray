## Capabilities

Groq covers all three pipeline stages with a single API key. 5–10x faster than equivalent GPU-based providers.

## Quick Config

```json
{
  "stt_provider": "groq",
  "llm_provider": "groq",
  "tts_provider": "groq",
  "model": "llama-3.1-8b-instant",
  "stt_model": "whisper-large-v3-turbo",
  "api_keys": { "groq": "gsk_..." }
}
```

Get a free key at [console.groq.com](https://console.groq.com).

## Limitations

- No MCP tool calling
- No Realtime mode
- Rate limits on free tier (per model/day)
