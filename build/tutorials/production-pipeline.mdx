## Overview

| Stage | Provider | Model | Why |
| --- | --- | --- | --- |
| STT | Groq | `whisper-large-v3-turbo` | Lowest latency STT |
| LLM | Anthropic | `claude-haiku-4-5-20251001` | Best reasoning quality |
| TTS | ElevenLabs | Custom voice ID | Most natural voice synthesis |

## Prerequisites

- Groq API key
- Anthropic API key
- ElevenLabs API key \+ Voice ID
- Redis instance
- PostgreSQL instance
- S3-compatible bucket with credentials
