## Overview

Voxray supports a large and growing set of AI providers for STT, LLM, TTS, and real-time pipeline tasks. Each task is configured independently — you can mix and match providers freely.

## Realtime Providers

Realtime providers bypass the standard STT → LLM → TTS pipeline.

| Provider | Notes |
| --- | --- |
| **OpenAI Realtime** | Low-latency bidirectional audio via `gpt-4o-realtime-preview` |
| **Hume** | Emotion-aware voice |
| **Inworld** | Game/character-oriented |

<Note>
  Daily.co and LiveKit are supported as **transport** providers via `runner_transport`, not as realtime AI providers.
</Note>
