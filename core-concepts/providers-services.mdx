## What are services?

Voxray organizes all AI calls behind three Go interfaces: `STTService`, `LLMService`, and `TTSService`. The rest of the pipeline never imports a provider SDK directly. Swap from OpenAI Whisper to Groq’s transcription endpoint by changing one key in `config.json`.

## Service interfaces

```go
// STTService — batch transcription.
type STTService interface {
    Transcribe(ctx context.Context, audio []byte, sampleRate, numChannels int) ([]*frames.TranscriptionFrame, error)
}

// TTSService — batch synthesis.
type TTSService interface {
    Speak(ctx context.Context, text string, sampleRate int) ([]*frames.TTSAudioRawFrame, error)
}

// LLMService — chat completion with optional token streaming.
type LLMService interface {
    Chat(ctx context.Context, messages []map[string]any, onToken func(*frames.LLMTextFrame)) error
}
```

## Factory functions

| Function | Purpose |
| --- | --- |
| `NewLLMFromConfig(cfg, provider, model)` | Returns an `LLMService` for `provider` |
| `NewSTTFromConfig(cfg, provider)` | Returns an `STTService` for `provider` |
| `NewTTSFromConfig(cfg, provider, model, voice)` | Returns a `TTSService` for `provider` |
| `NewServicesFromConfig(cfg)` | Resolves all three services at once |

## API key resolution

1. `config.api_keys[serviceName]` — value in the JSON config
2. Environment variable — e.g. `OPENAI_API_KEY`
3. Empty string — authentication will fail at first API call

## Realtime providers

Some providers expose a single bidirectional session that merges STT, LLM, and TTS. Use `realtime.NewFromConfig(cfg, provider)` to construct; never call the individual factory functions.

| Provider | Notes |
| --- | --- |
| **OpenAI Realtime** | Low-latency via `gpt-4o-realtime-*`; supports function calling |
| **Hume** | Emotion-aware voice |
| **Inworld** | Game/character-oriented |

Realtime path:

```text
AudioIn → RealtimeSession.SendAudio() ► RealtimeSession.Events() → AudioOut/TextOut
```
